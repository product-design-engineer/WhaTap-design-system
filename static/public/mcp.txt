# WhaTap Design System — MCP 연결 빠른 안내

WhaTap 디자인 시스템은 Storybook MCP(`@storybook/addon-mcp`)로 AI 코딩 도구에 연결됩니다.
이 도구로 AI가 이 DS 기준의 스토리 작성·컴포넌트 프리뷰·규약 조회를 수행합니다.

## 엔드포인트

    http://localhost:5181/mcp        (transport: streamable HTTP)

※ 로컬 `storybook dev` 실행 중에만 동작. 배포 정적 Storybook 에는 MCP 없음(지식은 /design-system/DESIGN.md 로 주입).

## 1) dev 서버 실행

    git clone https://github.com/interfacedesigner/WhaTap-design-system.git
    cd WhaTap-design-system && pnpm install && pnpm storybook   # 5181

## 2) AI 클라이언트 등록

Claude Code:
    claude mcp add --transport http whatap-ds http://localhost:5181/mcp

Cursor — .cursor/mcp.json:
    { "mcpServers": { "whatap-ds": { "url": "http://localhost:5181/mcp" } } }

VS Code (Copilot) — .vscode/mcp.json:
    { "servers": { "whatap-ds": { "type": "http", "url": "http://localhost:5181/mcp" } } }

Windsurf / 기타: HTTP MCP 서버로 http://localhost:5181/mcp 등록.

## 3) 지식도 함께 주입 (권장)

    curl https://whatap-design-system-storybook.vercel.app/design-system/DESIGN.md > whatap-ds.md

## 전체 절차/설명
