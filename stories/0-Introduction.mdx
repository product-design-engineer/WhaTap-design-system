WhaTap 제품의 디자인 시스템 **단일 출처** — 토큰 · Primitives · Chrome · AI 위젯 카드. `@whatap/design-system` 패키지 + Storybook + `tokens.css`.

- **합성 패턴:** 페이지 헤더 invariant · 사이드바 collapse · DataTable density · 타이포 위계 · AI 영역 분리. → [patterns.md](/design-system/patterns.md).

## 카탈로그 개요

전체 카탈로그는 **좌측 트리**가 정본이며, 각 항목의 Docs 에 prop·예시·When to use/NOT 이 있습니다. 구성:

- **Tokens** — 색 · 타입 스케일(11단계) · 웨이트 · 라인하이트 · 트래킹 · Tone(semantic). `tokens.css` 의 `@theme static` 단일 출처.
- **Primitives 14** — 일반 폼 9 (Checkbox · TextField · Select · Modal · Tabs …) + AI 카드 빌딩 블록 5 (AiCard · AiToneBadge · AiSectionHeading …)
- **Chrome 20** — 레이아웃(DashboardLayout · Sidebar · PageHeader · PageHeaderAiInline · SubHeaderBar) · 옵션바 · 데이터(DataTable · MiniLineChart · EventWeekTimeMatrix) · 알림/상태(Toast · Stage)
- **AI 진입 4** — AiAssistantButton · AiSendButton · AiInlinePrompt · AiPromptInput
- **Widget Cards 20+** — AI 응답 메시지 카드 (AiReasoning · AiCostTable · AiMigPlan · AiExecutionResult …)
- **Foundation** — WhaTap Symbol(4-bar 핀휠) + Horizon 워드마크

### 의존 방향 (역방향 import 금지)

```
Tokens   ←   Primitives   ←   Chrome / AI 진입 / Widget Cards
```

Tokens 는 leaf(누구도 import 안 함) · Primitives 는 Tokens 만 import · Chrome/AI/Widget 은 Primitives + Tokens import. 자세한 규칙: [patterns.md](/design-system/patterns.md).

## 5 핵심 규칙

이 5가지만 지키면 디자인 시스템의 80%를 따른 것입니다. 자세한 근거는 [patterns.md](/design-system/patterns.md).

1. **인라인 색상 리터럴 금지** — `#E53935` 같은 hex 를 컴포넌트에 직접 쓰지 마세요. `tokens.css` 의 `@theme` 변수나 `TONE_*` 토큰 참조. 새 톤은 토큰에 먼저 추가.
2. **위젯 카드는 `<AiCard>` 로 감싼다** — 흰 배경 + 보더 + 8px 라운드 + 12px 패딩 + 진입 애니메이션은 `AiCard` 가 책임. div 를 새로 짜면 톤이 어긋남.
3. **AI 위젯이 열려도 페이지 헤더는 그대로** — 사이드바는 240→40px 로 축소되지만, 헤더의 title / AI / Docs / 고객지원 / bell / avatar 는 절대 사라지지 않음.
4. **차트 텍스트는 단위까지** — SVG 안의 `<text fontSize>` 는 반드시 `"9px"` 처럼 단위를 붙임. 단위 없는 숫자는 viewBox 좌표로 계산되어 화면마다 크기가 달라짐.
5. **DataTable density 기본 `default`** — header 12px / row 13px. compact (10/11) 는 100+ 행 raw log 한정. 셀 내 inline 폰트는 `text-md`(주) / `text-base`(부) 만 사용.

## 빠른 시작

### 신규 페이지 작성

```tsx
import {
  DashboardLayout, PageHeaderAiInline, OptionbarPage,
  WhaTapAiWidget, useWhaTapAi,
  type AiPromptSuggestion,
} from "@whatap/design-system";

const PAGE_AI_SUGGESTIONS: AiPromptSuggestion[] = [
  { label: "DB 시간대별 사용량", query: "Oracle DB 24시간 사용량 분석" },
  { label: "병목 조회 분석",     query: "느린 쿼리 TOP 5 분석" },
];

export default function MyPage() {
  const { aiActive, setAiActive } = useWhaTapAi();
  return (
    <DashboardLayout
      activeProduct="db"
      widgetOpen={aiActive}
      header={<PageHeaderAiInline
        title="DB / oracle_dnx"
        promptSuggestions={PAGE_AI_SUGGESTIONS}
        onPromptSubmit={(q) => { setAiActive(true); /* 핸들 */ }}
      />}
      main={<MyContent />}
    >
      <WhaTapAiWidget open={aiActive} onClose={() => setAiActive(false)} />
    </DashboardLayout>
  );
}
```

### 신규 AI 응답 메시지

```tsx
import {
  AiCard, AiSectionHeading, AiBulletList,
  type SemanticIntent,
} from "@whatap/design-system/widget";

function CriticalFinding({ intent, title, bullets }: {
  intent: SemanticIntent;
  title: string;
  bullets: string[];
}) {
  return (
    <AiCard delay={0}>
      <AiSectionHeading tone={intent}>{title}</AiSectionHeading>
      <AiBulletList items={bullets} />
    </AiCard>
  );
}
```

**짧음에 주목**하세요. 새 색이 필요 없고, 새 폰트도 없고, 새 카드 chrome 도 없습니다. 디자인 시스템이 잘 작동하면 이렇게 짧아집니다.
