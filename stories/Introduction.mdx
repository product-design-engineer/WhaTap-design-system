## 카탈로그

정본은 좌측 트리입니다. AI 에셋은 따로 떼지 않고 각 계층 안 `Ai/` 로 묶습니다.

- **Tokens** (메타) — 12항목 / 295토큰
  - `:root` 색 · 타입 · 간격 · 그림자 · 컴포넌트 토큰
  - Color · Typography · Tones · Guardrails
- **Primitives** — 92
  - 자체 렌더 리프. 다른 DS 컴포넌트를 import 하지 않습니다.
  - Button · TextField · Select · Modal · Toast · Chip · Icons · ToolbarIconButton · `Topology/` · `Ai/`(AiCard · AiToneBadge …)
- **Composite** — 43
  - 프리미티브를 한 단계 조합합니다.
  - PageHeader · Sidebar · DataTable · FilterBar · OptionbarPage · TimeChip · ActionMenu · `Ai/`(AiReasoning · AiUnavailableNotice …)
- **Shell** — 6
  - 최종 조립 진입점.
  - DashboardLayout · `Ai/Widget` · `Page/`(A · B · D · TopologyOverview)

`PageHeaderAiInline` 은 AI 입력을 품지만 구조는 프리미티브 조합이라 `Composite/` 입니다.

### 의존 방향

```
Tokens   ←   Primitives   ←   Composite   ←   Shell
```

- **Primitives** — Tokens 만 import. 상위 계층 금지.
- **Composite** — Primitives · Tokens. **Composite 끼리는 금지**입니다.
  - 필요하면 Shell 로 승격합니다.
- **Shell** — 전 계층 가능.

문서가 아니라 게이트가 지킵니다.

- `lint:layers` — 역방향 값 import 동결선 **0**.
- 계층 판정 근거는 **story title prefix** 입니다.
  - 그래서 **스토리 없는 컴포넌트는 계층도 없고 게이트 밖**입니다.
  - 「공개 export 는 카탈로그에 있어야 한다」가 별도 게이트인 이유입니다.

## 다섯 가지 핵심 규칙

### 1. 색 리터럴 0 (불변)

- hex · `rgba()` · `bg-white` · 값이 이름에 박힌 유틸을 쓰지 않습니다.
- 토큰이 없으면 **토큰을 먼저 추가**합니다.
  - 토큰 부재는 리터럴의 근거가 아니라 토큰 추가의 근거입니다.
- TS 토큰 주입은 `.value` 가 아니라 **`.cssVar`** — `.dark` 는 변수만 바꾸므로 hex 를 박으면 다크가 안 따라옵니다.
- 소스 · 렌더된 DOM · 시각 스냅샷 **3중**으로 검사합니다.

### 2. 위젯 카드는 `<AiCard>`

- 배경 · 보더 · 8px 라운드 · 12px 패딩 · 진입 애니메이션이 그 컴포넌트 책임입니다.
- div 로 짜면 1px 어긋남이 보입니다.

### 3. 헤더(48px)는 invariant

- 위젯이 열리면 **사이드바만** 240 → **80px** 로 줄어듭니다.
  - 제품 레일 40 + 아이콘 메뉴 40.
- `DashboardLayout` 에 `widgetOpen` 만 넘기면 내부에서 처리합니다.

### 4. SVG 텍스트에 단위

- `fontSize="9px"` 처럼 단위를 붙입니다.
- 단위가 없으면 viewBox 좌표로 해석돼 **카드 크기마다 글자가 달라집니다.**

### 5. DataTable density `default`

- header 12px / row 13px.
- `compact`(10 / 11)는 **100행 넘는 raw log 전용**입니다.
- 셀 안은 `text-md`(주) · `text-base`(부) 두 개만 씁니다.

전체 게이트 22종은 **[Guardrails](/?path=/docs/tokens-guardrails--docs)** 에 있습니다. 손으로 적은 목록이 아니라 명부(`gate-roster.mjs`)에서 생성한 projection 입니다.

## 빠른 시작

### 새 페이지

```tsx
import {
  DashboardLayout, PageHeaderAiInline, OptionbarPage,
  WhaTapAiWidget, useWhaTapAi,
  type AiPromptSuggestion,
} from "@whatap/design-system";

const PAGE_AI_SUGGESTIONS: AiPromptSuggestion[] = [
  { label: "DB 시간대별 사용량", query: "Oracle DB 24시간 사용량 분석" },
  { label: "병목 조회 분석",     query: "느린 쿼리 TOP 5 분석" },
];

export default function MyPage() {
  const { aiActive, setAiActive } = useWhaTapAi();
  return (
    <DashboardLayout
      activeProduct="db"
      widgetOpen={aiActive}          // 사이드바 240→80px 축소를 내부에서 처리
      header={<PageHeaderAiInline
        title="DB / oracle_dnx"
        promptSuggestions={PAGE_AI_SUGGESTIONS}
        onPromptSubmit={(q) => { setAiActive(true); /* 핸들 */ }}
      />}
      main={<MyContent />}
    >
      <WhaTapAiWidget open={aiActive} onClose={() => setAiActive(false)} />
    </DashboardLayout>
  );
}
```

### 새 AI 응답 메시지

```tsx
import { AiCard, AiSectionHeading, AiBulletList, type SemanticIntent } from "@whatap/design-system/widget";

function CriticalFinding({ intent, title, bullets }: {
  intent: SemanticIntent; title: string; bullets: string[];
}) {
  return (
    <AiCard delay={0}>
      <AiSectionHeading tone={intent}>{title}</AiSectionHeading>
      <AiBulletList items={bullets} />
    </AiCard>
  );
}
```

**짧음에 주목**하세요. 새 색도, 새 폰트도, 새 카드 chrome 도 없습니다. 디자인 시스템이 잘 작동하면 이렇게 짧아집니다.

### 삭제 버튼 (자주 틀리는 곳)

```tsx
<Button tone="critical" size="sm" onClick={() => setConfirm(true)}>삭제</Button>

<Modal open={confirm} onClose={() => setConfirm(false)} size="sm" title="알림 규칙 삭제"
  footer={<>
    <Button variant="basic" onClick={() => setConfirm(false)}>취소</Button>
    <Button variant="contained" tone="critical" onClick={remove}>삭제</Button>
  </>}>
  「CPU 90% 초과」 규칙을 삭제합니다. 되돌릴 수 없습니다.
</Modal>
```

- 확인 버튼 라벨은 "확인"이 아니라 **동작 이름**(`삭제`)입니다.
  - 버튼만 읽고 누르는 사람이 있고, 그 사람이 틀리지 않아야 합니다.
- 본문에는 **무엇이** 사라지는지 대상을 적습니다.
- `disableBackdropClose` 를 켜지 않습니다.
  - 되돌릴 수 없는 것은 *확인*이고, *취소*는 언제나 쉬워야 합니다.
- 전문은 patterns Part 1 의 `P1`.
