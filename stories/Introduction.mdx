# WDS — WhaTap Design System

WhaTap 제품 UI 의 단일 출처입니다.

| | 수 | 비고 |
|---|---|---|
| 토큰 | **197** | Semantic 111 · Global 68 · Component 18 · 다크 재매핑 60 |
| 컴포넌트 | **115** | Primitives 75 · Composite 34 · Shell 6 |
| 카탈로그 항목 | **127** | 위 115 + Tokens 메타 12 |
| 스토리 엔트리 | **615** | Storybook `index.json` |
| 무결성 게이트 | **22** | 자동 16 · 정책 4 · 계획 2 |

> 수치는 생성 산출물과 맞춰 둡니다(2026-08-21). 좌측 트리와 어긋나면 문서 버그입니다.

## 시작 — 프론트엔드 개발자

```bash
npm i https://whatap-design-system-storybook.vercel.app/releases/whatap-design-system-latest.tgz
```

```ts
import { DashboardLayout, PageHeader, DataTable } from "@whatap/design-system";
import "@whatap/design-system/style.css";   // 런타임 스타일은 이것 하나
```

- clone 불필요. Vite · Next · webpack 모두 동작. 버전 목록은 [releases/index.json](/releases/index.json).
- ⚠️ **`tokens.css` 를 import 하지 마세요.** 토큰 `:root` 만 들어 있어 색은 맞고 레이아웃이 무너집니다. 유틸·전역·`.dark` 는 `style.css` 에만 있습니다.
- **AI 연결**: `https://whatap-ds-mcp.vercel.app/mcp` (dev 서버 불필요). 라이브 도구는 로컬 `:5181/mcp`. 절차 [AI-INTEGRATION.md](/design-system/AI-INTEGRATION.md) · [mcp.txt](/mcp.txt) · [llms.txt](/llms.txt).
- **지킬 것 둘**: 인라인 hex 금지(토큰 참조) · 컴포넌트 인라인 재구현 금지(prop 조합).

## 시작 — 디자이너

- **토큰 197개**에 전부 `@role`(무엇을 위한 값인가)이 붙어 있습니다. 다수는 `@use`(권장) · `@avoid`(금지)까지. 값이 아니라 역할로 고릅니다. → [Color](/?path=/docs/tokens-color--docs) · [Typography](/?path=/docs/tokens-typography--docs) · [Tones](/?path=/docs/tokens-tones-semantic-intent--docs) · [tokens.json](/design-system/tokens.json)
- **컴포넌트**는 항목마다 "언제 쓰고 언제 쓰지 말지"가 적혀 있습니다. → 좌측 트리
- **[patterns.md](/design-system/patterns.md)** 는 두 부분입니다.
  - Part 1 인터랙션 패턴: 파괴적 액션 확인 · 완료 통보 · 즉시반영 vs 폼제출
  - Part 2 구현 정책: 헤더 invariant · 사이드바 collapse · DataTable density · 타이포 위계 · AI 영역 분리
- **Figma 연동은 없습니다.** Code Connect 매핑 0건, Variables 동기화 없음. 정본은 이 Storybook 이고, 토큰을 Figma 로 옮기려면 `node scripts/design-export.js dtcg`(W3C DTCG JSON).

## 카탈로그

정본은 좌측 트리입니다. AI 에셋은 따로 떼지 않고 각 계층 안 `Ai/` 로 묶습니다.

| 그룹 | 수 | 의미 | 예 |
|---|---|---|---|
| **Tokens** (메타) | 12 / 197토큰 | `:root` 색·타입·간격·그림자·컴포넌트 토큰 | Color · Typography · Tones · Guardrails |
| **Primitives** | **75** | 자체 렌더 리프. 다른 DS 컴포넌트 import 0 | Button · TextField · Select · Modal · Toast · Chip · Icons · ToolbarIconButton · `Topology/` · `Ai/`(AiCard · AiToneBadge …) |
| **Composite** | **34** | 프리미티브 한 단계 조합 | PageHeader · Sidebar · DataTable · FilterBar · OptionbarPage · TimeChip · `Ai/`(AiReasoning · AiUnavailableNotice …) |
| **Shell** | **6** | 최종 조립 진입점 | DashboardLayout · `Ai/Widget` · `Page/`(A · B · D · TopologyOverview) |

`PageHeaderAiInline` 은 AI 입력을 품지만 구조는 프리미티브 조합이라 `Composite/` 입니다.

### 의존 방향

```
Tokens   ←   Primitives   ←   Composite   ←   Shell
```

| 계층 | import 가능 | 금지 |
|---|---|---|
| Primitives | Tokens | 상위 계층 |
| Composite | Primitives · Tokens | **Composite 끼리** (필요하면 Shell 로 승격) |
| Shell | 전 계층 | — |

- 문서가 아니라 게이트가 지킵니다(`lint:layers`, 역방향 값 import 동결선 **0**).
- 계층 판정 근거는 **story title prefix**. 그래서 **스토리 없는 컴포넌트는 계층도 없고 게이트 밖**입니다. 「공개 export 는 카탈로그에 있어야 한다」가 별도 게이트인 이유입니다.

## 다섯 가지 핵심 규칙

| # | 규칙 | 핵심 |
|---|---|---|
| 1 | **색 리터럴 0** (불변) | hex · `rgba()` · `bg-white` · 값이 이름에 박힌 유틸 금지. 토큰이 없으면 **토큰을 먼저 추가**. TS 토큰 주입은 `.value` 아니라 **`.cssVar`**(`.dark` 는 변수만 바꿈). 소스 · 렌더된 DOM · 시각 스냅샷 3중 검사 |
| 2 | **위젯 카드는 `<AiCard>`** | 배경 · 보더 · 8px 라운드 · 12px 패딩 · 진입 애니메이션이 그 컴포넌트 책임. div 로 짜면 1px 어긋남이 보임 |
| 3 | **헤더(48px)는 invariant** | 위젯이 열리면 사이드바만 240 → **80px**(제품 레일 40 + 아이콘 메뉴 40). `DashboardLayout` 에 `widgetOpen` 만 넘기면 내부 처리 |
| 4 | **SVG 텍스트에 단위** | `fontSize="9px"`. 단위 없으면 viewBox 좌표로 해석돼 카드 크기마다 글자가 달라짐 |
| 5 | **DataTable density `default`** | header 12px / row 13px. `compact`(10/11)는 100행 넘는 raw log 만. 셀 안은 `text-md`(주) · `text-base`(부) 두 개만 |

전체 게이트 22종은 **[Guardrails](/?path=/docs/tokens-guardrails--docs)** 에 있습니다. 손으로 적은 목록이 아니라 명부(`gate-roster.mjs`)에서 생성한 projection 입니다.

## 빠른 시작

### 새 페이지

```tsx
import {
  DashboardLayout, PageHeaderAiInline, OptionbarPage,
  WhaTapAiWidget, useWhaTapAi,
  type AiPromptSuggestion,
} from "@whatap/design-system";

const PAGE_AI_SUGGESTIONS: AiPromptSuggestion[] = [
  { label: "DB 시간대별 사용량", query: "Oracle DB 24시간 사용량 분석" },
  { label: "병목 조회 분석",     query: "느린 쿼리 TOP 5 분석" },
];

export default function MyPage() {
  const { aiActive, setAiActive } = useWhaTapAi();
  return (
    <DashboardLayout
      activeProduct="db"
      widgetOpen={aiActive}          // 사이드바 240→80px 축소를 내부에서 처리
      header={<PageHeaderAiInline
        title="DB / oracle_dnx"
        promptSuggestions={PAGE_AI_SUGGESTIONS}
        onPromptSubmit={(q) => { setAiActive(true); /* 핸들 */ }}
      />}
      main={<MyContent />}
    >
      <WhaTapAiWidget open={aiActive} onClose={() => setAiActive(false)} />
    </DashboardLayout>
  );
}
```

### 새 AI 응답 메시지

```tsx
import { AiCard, AiSectionHeading, AiBulletList, type SemanticIntent } from "@whatap/design-system/widget";

function CriticalFinding({ intent, title, bullets }: {
  intent: SemanticIntent; title: string; bullets: string[];
}) {
  return (
    <AiCard delay={0}>
      <AiSectionHeading tone={intent}>{title}</AiSectionHeading>
      <AiBulletList items={bullets} />
    </AiCard>
  );
}
```

**짧음에 주목**하세요. 새 색도, 새 폰트도, 새 카드 chrome 도 없습니다. 디자인 시스템이 잘 작동하면 이렇게 짧아집니다.

### 삭제 버튼 (자주 틀리는 곳)

```tsx
<Button tone="critical" size="sm" onClick={() => setConfirm(true)}>삭제</Button>

<Modal open={confirm} onClose={() => setConfirm(false)} size="sm" title="알림 규칙 삭제"
  footer={<>
    <Button variant="basic" onClick={() => setConfirm(false)}>취소</Button>
    <Button variant="contained" tone="critical" onClick={remove}>삭제</Button>
  </>}>
  「CPU 90% 초과」 규칙을 삭제합니다. 되돌릴 수 없습니다.
</Modal>
```

- 확인 버튼 라벨은 "확인"이 아니라 동작 이름(`삭제`). 버튼만 읽고 누르는 사람이 있습니다.
- 본문에는 **무엇이** 사라지는지 대상을 적습니다.
- `disableBackdropClose` 를 켜지 않습니다. 되돌릴 수 없는 건 확인이고, 취소는 쉬워야 합니다.
- 전문은 patterns Part 1 의 `P1`.

## AI 에이전트 규약

```bash
curl .../design-system/DESIGN.md          # 사람이 읽는 산문 합본
curl .../design-system/components.json    # 기계 판독 — 컴포넌트 규칙 127
curl .../design-system/tokens.json        # 기계 판독 — 토큰 197
```

- **docstring 표준은 게이트가 강제합니다.** Purpose / When to use / When NOT to use / Composition rules + `@example`. Do/Don't 는 여기서 유도되므로 따로 쓰지 않습니다.
- 스토리 안에서 정의되는 합성 템플릿(`Shell/Page/*`)은 **스토리 설명**에 같은 4섹션을 씁니다.
- 토큰은 선언 위 `@role` 주석이 같은 역할입니다. 현재 **197/197**.
